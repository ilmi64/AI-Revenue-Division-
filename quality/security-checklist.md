# Security and Privacy Checklist

- [ ] No passwords, API keys, tokens, private keys, seed phrases, cookies, or session files.
- [ ] No customer secrets, private communications, or confidential datasets.
- [ ] No personal identity documents or sensitive personal data.
- [ ] Synthetic or properly anonymised test data only.
- [ ] Dependencies and scripts are reviewed before execution.
- [ ] No hidden telemetry, credential collection, or unexpected network calls.
- [ ] Least privilege; no unnecessary account permissions.
- [ ] No wallet signing, custody, or financial transaction capability.
- [ ] Public repository content is safe for anyone to inspect.
- [ ] Any suspected secret exposure is treated as an incident: stop, notify owner, revoke/rotate through the account owner, and review history.
