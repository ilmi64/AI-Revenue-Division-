# Organisation Launch Readiness Package

This package coordinates ten active divisions for a controlled, evidence-based launch. Animora is on hold and excluded from active implementation.

- [Christmas 2026 Fast-Track](CHRISTMAS-2026-FAST-TRACK.md) — dated countdown, parallel division priorities, Actions release-day sequence and Tier A decision gate.
- [Organisation Launch Readiness Plan](ORGANISATION-LAUNCH-READINESS-PLAN.md) — launch tiers, governance and exit criteria.
- [Division Acceptance Matrix](DIVISION-ACCEPTANCE-MATRIX.md) — current evidence and per-division acceptance gates.
- [Integrated Rehearsal and Operations Runbook](INTEGRATED-REHEARSAL-AND-OPERATIONS-RUNBOOK.md) — end-to-end scenarios, stop conditions and handovers.
- [Launch Blocker Register](LAUNCH-BLOCKER-REGISTER.md) — current blockers and required closure evidence.
- [Repository Integration Order](REPOSITORY-INTEGRATION-ORDER.md) — reviewed PR dependency relationships and integration cautions.

These documents define a proposed readiness process. They do not establish that tests passed, systems are running, staff are assigned or launch is authorized. First target: Tier A controlled internal/read-only/paper launch. Live financial execution and external commercial actions remain separately gated.
