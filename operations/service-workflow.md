# AI-Assisted Service Workflow

## Initial offer hypothesis
Read-only ecommerce listing preflight audit using a customer-supplied CSV. Potential checks include missing SKU/title/price/quantity, invalid numeric values, zero or negative prices, missing URLs/variants, and a basic contribution estimate when cost and fee inputs are supplied.

## Workflow
1. Validate demand with public evidence and conversations only after owner approval.
2. Define scope, exclusions, turnaround, input format, and acceptance criteria.
3. Prepare a sample using synthetic data; never publish real customer data.
4. Test for false positives, edge cases, and clear explanations.
5. Draft a service description and sample report for owner review.
6. Owner approves pricing, client contact, and any engagement.
7. Collect only necessary data through an agreed secure method.
8. Deliver report plus remediation checklist; do not edit or publish marketplace listings.
9. Record time, fees, revisions, customer feedback, and actual payment.

## Claims
Do not claim guaranteed sales, compliance, complete marketplace compatibility, or error-free results. State supported checks and limitations plainly.
