# Animora IP and Creative Asset Register

**Purpose:** Establish a traceable inventory of original and third-party creative assets before production, licensing or commerce. This template is not proof of ownership or legal clearance.

## Register fields

| Field | Required information |
|---|---|
| Asset ID | Stable unique identifier |
| Asset / IP title | Character, world, story, script, design, logo, artwork, music, footage, software or other asset |
| Category | Character, world, literary, visual, audio, audiovisual, brand, software, reference or other |
| Description | Factual description and intended role |
| Creator / contributor | Person or organisation that created or supplied it |
| Creation date / version | Date, revision and source-control reference |
| Source location | Repository, file path or controlled storage reference |
| Ownership basis | Creator-owned, assigned, licensed, commissioned, public-domain claim, or unknown |
| Evidence reference | Signed agreement, dated source file, licence, invoice, release or other supporting record |
| Permitted uses | Development, app, film, publishing, merchandise, promotion, licensing, etc. |
| Restrictions / expiry | Territory, term, platform, attribution, modification, sublicensing and expiry limits |
| Third-party elements | Fonts, stock, references, models, music, voice, plugins or other embedded elements |
| Review status | Unreviewed, evidence pending, legal review required, cleared for stated scope, restricted |
| Approver / date | Named authorised reviewer and review date |
| Notes / incidents | Disputes, takedown requests, provenance gaps or corrective action |

## Required controls

1. Preserve original source files and version history; do not overwrite the only copy.
2. Separate inspiration/reference material from assets intended for use in a released work.
3. Record all contributors and obtain written rights documentation before accepting commissioned or collaborative work.
4. Check embedded third-party materials and AI-tool terms, including commercial-use, training, attribution and output restrictions.
5. Clear music, fonts, voices, likenesses, locations, trademarks and stock elements independently.
6. Record territory, duration, medium, sublicensing and merchandise rights separately; a licence for one use does not imply all uses.
7. Keep evidence access-controlled and retain a change log.
8. Escalate uncertainty or disputes for qualified legal review; do not mark an asset cleared based on assumption.
