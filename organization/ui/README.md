# OCC Offline Mobile Dashboard

A dependency-free, mobile-friendly, read-only viewer for the JSON report generated by the Organisation Control Centre.

## Generate a report

From the repository root, run:

```sh
python organization/tools/build_organisation_dashboard.py > occ-report.json
```

The command exits non-zero if its configured data-quality checks fail. Review the console exit status and the report's `data_quality` section; do not treat a generated file as proof of readiness.

## Open the viewer

Open `organization/ui/index.html` in a modern browser and load `occ-report.json`. It works as a local file and uses no external libraries, network calls, accounts, API keys, or paid services.

## Included views

- Organisation metrics and division scorecard
- Work queue with status filtering
- Risk escalations and pending decision prompts
- Data-quality warnings and approval-boundary reminders

## Security and scope

- Read-only display; it does not edit source records or persist uploaded report data.
- JSON is rendered using DOM text nodes, not interpreted as HTML.
- No credentials, secrets, private keys or customer data should be included in dashboard reports.
- No task assignment, dispatch, approvals, trading, signing, publishing, merging, deployment or account changes.
- This is a local viewer, not a hosted dashboard or unattended monitoring service.
- Report freshness is determined by when the source report was generated.
